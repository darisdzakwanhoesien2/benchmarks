Part 1 — Graph construction & analysis
1
ESG entity graph construction using NER
Build co-entity network from sustainability report sections

Use spaCy (+ custom ESG entity ruler) to extract named entities from each report section. Connect section nodes that share at least one entity. This constructs the foundational graph for all subsequent network analysis.

Original task analog

NER graph construction from bag_of_phrases; connect tweets sharing ≥1 entity; histogram of entity counts by type.

Adapted procedure
  • Extract entities per section: ORG (OJK, GRI, PROPER, ISO bodies), ENV (emission targets, biodiversity), POLICY (Paris Agreement, SDGs), METRIC (numeric disclosures), CERT (ISO 14001, PROPER Emas)
  • Build bipartite graph: section nodes ↔ entity nodes; project onto section–section unipartite graph where edge weight = number of shared entities
  • Apply minimum edge weight threshold (≥2 shared entities) to reduce noise
  • Plot histograms: entity count per type (ORG / POLICY / CERT / METRIC) across full corpus
ESG-specific addition
  • Separate graph per ESG pillar: E-graph, S-graph, G-graph — compare structural properties across pillars
  • Color-code nodes by sector (IDX) to reveal sector clustering in the graph layout
Expected outputs
NetworkX graph object Entity type histogram Gephi-ready .graphml

Degree distribution and centrality summary
Identify the most connected ESG sections in the network

Use NetworkX to compute and visualize degree distribution. High-degree nodes are sections that share entities with the widest range of other sections — these are structurally "central" ESG disclosures in Indonesian corporate reporting.

Metrics to compute and tabulate
Max degree

Section with most entity-sharing connections

Min degree

Isolated or near-isolated sections

Avg degree

Mean connectivity across all section nodes

Avg path length

Mean shortest path between any two connected sections

Degree centrality

Normalized degree per node; save as CSV

Density

Ratio of actual to possible edges

Plot
  • Degree distribution histogram (log–log scale to test power-law — common in entity co-occurrence networks)
  • Annotate top-5 highest-degree nodes with their company + pillar label
ESG interpretation
  • High-degree environmental sections that are hubs: do they belong to mining/extractive companies? (defensive ESG framing hypothesis)
  • Isolated (degree-0) nodes: sections with entirely unique or no recognized entities — flag as boilerplate-free or entity-poor
Save degree centrality scores to CSV indexed by company + year + pillar for use in Task 5 token correlation analysis.

Betweenness and closeness centrality analysis
Find sections that bridge ESG discourse communities

Compute betweenness and closeness centralities. In the ESG graph, high-betweenness sections are those whose entity vocabulary bridges otherwise disconnected ESG topics — potentially integrative or cross-pillar disclosures.

Original task analog

Compute and plot betweenness and closeness centralities. Save scores. Analyze top nodes' bag_of_phrases content.

Adapted procedure
  • Compute nx.betweenness_centrality(G, normalized=True) and nx.closeness_centrality(G)
  • Plot both distributions as bar charts (top-20 nodes each)
  • Save full scores to CSV: node_id, company, year, pillar, betweenness, closeness
Content analysis of top nodes
  • For the top-10 nodes by betweenness: extract their section text, identify which ESG aspects (from your 46-cluster taxonomy) appear most frequently
  • Hypothesis: high-betweenness sections mention cross-pillar entities (e.g., SDG goals that span E+S+G) — test this
  • For top-10 by closeness: these are sections most "reachable" from any other section — likely generic/templated language hubs
Greenwashing signal
  • Sections with high closeness but low sentiment specificity (vague positive language, few METRIC-type entities) may be isomorphic templates
  • Compare betweenness centrality between GRI-aligned vs non-aligned reports
4
Clustering coefficients and local structure analysis
Measure how tightly ESG sections cluster around shared entities

Calculate clustering coefficients for all nodes. A high clustering coefficient means a section's neighbors are also densely connected to each other — indicating a tight-knit ESG topic subgroup. Low coefficients indicate bridging nodes between sparse groups.

Procedure
  • Compute nx.clustering(G) for all nodes; save to CSV
  • Plot histogram with 10 bins: distribution of clustering coefficients across all section nodes
  • Compute global average clustering coefficient and compare to equivalent Erdős–Rényi random graph (same n, m) as a null model
ESG interpretation
  • Nodes with high clustering: likely belong to sector-specific ESG subgraphs (e.g., banking sector governance sections all citing OJK together)
  • Nodes with near-zero clustering despite moderate degree: true bridge nodes connecting otherwise separate ESG discourse clusters
  • Compare average clustering per sector: do mining companies form denser local clusters (due to shared environmental regulation citations)?
Expected outputs
Clustering coefficient CSV 10-bin histogram Random graph comparison

Part 2 — Simulation

ESG influence propagation simulation (Erdős number analog)
Model how ESG discourse spreads from the most-connected section

Replace the Erdős number simulation (BFS distance from highest-degree node) with an ESG influence propagation simulation. The highest-degree section node becomes the "ESG hub" — compute every other section's graph distance from it, analogous to Erdős numbers. Then extend with a simple diffusion simulation.

Original task analog

Use highest-degree node as "Erdős." Calculate other nodes' Erdős numbers via BFS. Save and plot distribution.

Part A — ESG Erdős number
  • Identify the highest-degree section node (the "ESG hub")
  • Compute BFS shortest path from hub to all connected nodes using nx.single_source_shortest_path_length(G, hub)
  • Save ESG distance scores to CSV: node_id, company, year, pillar, esg_distance
  • Plot distribution histogram — what fraction of sections are within 2 hops of the hub?
  • Analyze: which sectors / pillars tend to be farthest from the hub (most isolated ESG discourse)?
Part B — ESG discourse diffusion simulation
  • Simulate how a "greenwashing signal" (a specific vague entity, e.g., "net zero commitment") propagates across the network year-over-year
  • Use a simple SIR (Susceptible–Infected–Recovered) analog: sections "adopt" the phrase if ≥k neighbors contain it in prior year
  • Plot adoption curve across years — does the signal spread faster in denser sectors?
Expected outputs
ESG distance CSV BFS distance histogram Diffusion curve plot
The diffusion simulation is an original extension not in the original project — it directly supports your greenwashing isomorphic mimicry hypothesis (companies adopting ESG language from peer network neighbors).
