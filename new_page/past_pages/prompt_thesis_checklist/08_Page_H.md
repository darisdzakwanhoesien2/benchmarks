Part H: Quantitative and Experimental Verification

Recalculate, where sufficient information is available:

totals;
percentages;
averages;
precision;
recall;
F1 scores;
macro and weighted averages;
accuracy;
improvements;
relative improvements;
error reductions;
confidence intervals;
dataset splits;
row counts;
table totals.

Distinguish carefully between:

absolute percentage-point improvement;
relative percentage improvement;
relative error reduction.

For example, a change from 70% to 75% is:

a 5-percentage-point increase;
approximately a 7.14% relative increase.

Flag incorrect or ambiguous descriptions.

Create a numerical verification table:

| Location | Reported Value | Recalculated Value | Difference | Likely Explanation | Correction Needed |

Do not recalculate a value when the required raw information is absent. Mark it as unverifiable.
