e. Improvement of Cyber Threat Intelligence and Digital Right Protection technology

To enhance IT security visibility, BTN has implemented Cyber Threat Intelligence (CTI) technology, which actively monitors cybercriminal behavior and activities, allowing the Bank to anticipate potential threats. The Cyber Threat Intelligence (CTI) system is equipped with Digital Right Protection capabilities, enabling the takedown of harmful content that may damage the Bank's reputation and negatively impact customers.

f. Improvement of Mobile Application Security

To protect mobile applications used by customers, BTN has adopted a security-by-design approach in its application development process. Strengthening the security of customer access devices has also been prioritized through the implementation of Mobile Application Security measures.

g. Improvement of DNS Security and IP Address Management

As a mitigation measure to protect internal IT systems accessing online resources, DNS Security has been enhanced to prevent access to unsafe websites. The optimization of DNS security is combined with IP address management, ensuring traceability of endpoints accessing these IT resources.

h. Improvement of Internet Access Control and Proxy Outbound

To separate and identify data communications between transactional business activities and internal office productivity communications, improvements have been made to Internet Access Control by implementing separate internet access and outbound proxy solutions.

i. Improvement of Email Security

To protect devices and email systems from cyber threats, security measures have been strengthened against spam, phishing, and malicious email attachments.

j. Enhancement of Infrastructure Availability and Resilience

By implementing active-active security infrastructure, BTN ensures the reliability of its transactional banking services.

k. Improvement of API Security

As open banking adoption increases, so does the risk of API-based cyber threats. Therefore, API security enhancements have been implemented to detect and prevent API-based attacks.

l. Improvement of Internet Banking Business (IBB) Security

To support business banking services for MSMEs, BTN has introduced a web-based Internet Banking Business platform. As part of this, web application security has been enhanced, and content delivery network (CDN) technology has been integrated to improve website performance.

m. Improvement of Application Security through Manage Service Digital Application Protection

With increasing digital transactions via mobile banking, comprehensive security measures have been implemented to protect both the technology and operational monitoring aspects of mobile banking applications.

n. Improvement of Database Security

As digital transactions grow, so does database access activity. Therefore, specific security measures have been put in place to limit and prevent database exploit-based cyberattacks.

o. Improvement of IT System Management and Security Based on Microsoft Technologies

Due to the extensive use of Microsoft technologies in BTN's operations, including Windows operating systems, Active Directory, MSSQL databases, Microsoft Office productivity applications, and Office 365 cloud services, security risks can arise if these systems are not managed according to best practices. Through collaboration with Microsoft professional services, BTN has implemented the latest security measures, enhanced operational support, and gained access to cutting-edge technology from Microsoft.
