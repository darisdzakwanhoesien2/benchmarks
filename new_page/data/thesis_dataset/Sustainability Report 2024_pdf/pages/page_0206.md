# 3. Technology

Throughout 2024, BTN continuously enhanced IT security capabilities by optimizing defense-in-depth strategies. This consists of multiple security layers, including endpoint security, application security, network security, IT infrastructure security, and data security. These enhancements

include Network Access Control (NAC), Endpoint Protection improvements for servers, Network Time Protocol (NTP) improvements, Data Loss Prevention (DLP), Cyber Threat Intelligence and Digital Right Protection, Mobile Application Security enhancements, DNS Security improvements, Internet Access Control and Proxy Outbound improvements, email security improvements, transaction infrastructure availability and resilience improvements with active-active security implementation, API security improvements, Internet Banking Business security enhancements, application security improvements through managed digital application protection services, database security improvements, and IT system security enhancements based on Microsoft technologies.

a. Implementation of Network Access Control (NAC)

This technology functions to regulate, verify, and monitor device access to networks based on security policies, ensuring data protection from unauthorized access and potential threats.

b. Improvement of Endpoint Protection technology for servers

This enhancement is designed to identify, prevent, and respond to threats affecting network-connected devices, such as malware, ransomware, and other harmful activities, ensuring data protection against leaks, damage, or theft through real-time detection and protection.

c. Improvement of Network Time Protocol (NTP) This measure ensures accurate time synchronization across networks, helping maintain correct timestamps for audit logs, preventing data manipulation, and supporting system security by ensuring time consistency in customer data encryption and authentication protocols.

d. Improvement of Data Loss Prevention (DLP) technology

As part of its commitment to protecting customer data, BTN has implemented Data Loss Prevention (DLP) technology to mitigate the risk of customer and corporate data breaches.
