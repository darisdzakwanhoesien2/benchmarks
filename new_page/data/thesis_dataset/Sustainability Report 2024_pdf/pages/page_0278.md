# Ethics Guidelines Internalization Process

|  Education | Application | Reporting and Follow-Up Actions  |
| --- | --- | --- |
|  • The Code of Conduct is disseminated and accessible to all Bank personnel through the Digital Room for E-learning Modules (DREAM). Additionally, quizzes regarding the Code of Conduct are conducted to evaluate employees' understanding.
• Commitment to implementing the Code of Conduct is stipulated in the Integrity Pact, which must be signed by all members of the Board of Directors, Board of Commissioners, and Bank employees. The Code of Conduct is also accessible to all stakeholders through the company's website. | • Signing of the Integrity Pact by all employees, aligned with the values of the Code of Conduct.
• Internalization of the Code of Conduct, anti-gratuity controls, and the Anti-Bribery Management System (ABMS) for all employees via Digital Room for E-learning Modules (DREAM).
• Collaborating with the Corruption Eradication Commission (KPK) through the Professional Integrity (PROFIT) program, which includes competent Human Resources (HR) support to enhance integrity in overseeing corruption prevention within the Bank, participation in training programs as certification of Integrity Builder Expert, certification of Anti-Corruption Counselors (PAKSI), and collaboration in KPK anti-corruption campaigns via various communication media.
• Implementing anti-gratuity control programs as planned and submitting periodic reports on its implementation to the KPK each semester.
• Managing reports of gratuity acceptance from all work units and reporting them to the KPK in accordance with regulations. | • 37001:2016 as part of the enforcement of business ethics and behavior outlined in the Code of Conduct.
• Implementing the Whistleblowing System (WBS) program.
• Imposing sanctions on employees who violate the Code of Conduct.  |
