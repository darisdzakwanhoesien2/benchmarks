# BTN Properti

BTN Properti is a platform designed to facilitate home purchases, property searches, and access to 3D viewing features through the latest digital technology. BTN Properti offers a diverse selection of properties from developers that have partnered with BTN across Indonesia.

## Key Features of BTN Properti

- Search
Consumers can search for properties based on location, developer name, or housing complex name.

- Loan Simulation
Consumers can calculate their loan application to determine the estimated installment amount.

- Online Loan Application
Consumers can submit loan applications online.

- Loan Application Tracking
Consumers can monitor the status of their loan applications.

- 4D Tour Service
Consumers can virtually visit show units using a four-dimensional (4D) tour feature.
