# THE PERMATABANKERS
The PermataBankers

Sikap kerja 4 E dipadu dengan motivasi pribadi dan tata nilai PermataBank dioperasikan untuk menghasilkan keluaran yang diharapkan dengan menggunakan seperangkat kelengkapan organisasi berupa:
- Kode Etik
- Good Corporate Governance (GCG)
- Sistem Manajemen

Sistem budaya disosialisasikan dan diinternalisasikan kepada PermataBankers antara lain melalui program orientasi karyawan baru (NEOP: New Employee Orientation Program) dan pelatihan kepemimpinan.

Selain itu, sistem budaya terinternalisasi melalui pelatihan wajib antara lain kode etik karyawan, anti money laundering, kampanye anti fraud baik melalui kelas maupun secara on-line, dengan keharusan penyegaran secara regular.

4 Es work attitudes combined with personal motivation and values of Permata Bank is activated to generate expected output by using a set of organizational instrument in the form of:
- Code of Conduct
- Good Corporate Governance (GCG)
- Management System

Culture system socialized and internalized to PermataBankers, among others, through new employee orientation program (NEOP) and leadership training.

In addition, the cultural system is internalized through mandatory trainings which include employee's code of conduct, anti-money laundering, and anti-fraud campaign both through classroom as well as on-line, that require regular refreshment.
