# 2. EVALUASI KINERJA DAN PENGEMBANGAN KARIR

# [G4-LA11]

Sebagai organisasi berbasis kinerja, PermataBank melakukan evaluasi kinerja karyawan pada tengah dan akhir tahun. Penilaian dilakukan berdasarkan hasil pencapaian dibandingkan dengan target kerja dimana target kerja merupakan turunan dari target unit kerja, dan target unit kerja adalah turunan dari target organisasi yang lebih besar.

Pemberian umpan balik dan coaching merupakan bagian terpenting dari diskusi penilaian kinerja. Disinilah letak pembelajaran yang sesungguhnya. Oleh karenanya, para manajer didorong untuk memberikan umpan balik dan coaching bukan hanya pada sesi penilaian kinerja melainkan secara kontinyu setiap kali dipandang diperlukan.

Dalam rangka pengembangan kemampuan dan karir, dalam hal seorang karyawan dipandang memerlukan, maka untuk memperbaiki kinerja yang bersangkutan diberikan Bimbingan dan Pembinaan Kinerja (BPK) berdurasi 6 – 18 bulan.

# 2. PERFORMANCE EVALUATION AND CAREER DEVELOPMENT [G4-LA11]

As a performance-based organization, PermataBank regularly conducts employees' performance evaluation. The evaluation is conducted based on performance achievement compared to target derived from working unit target, while working unit target is derived from a bigger organizational target.

Feedback and coaching are important part of discussion on performance evaluation. This is where the real learning process taken place. Therefore, managers are encouraged to give feedback and coaching not only on performance evaluation sessions. It is a continuous effort that should be done whenever it is necessary.

In order to develop abilities and careers, if it is deemed required, an employee will be given a BPK (Performance Guidance and Counselling Plan) of 6-18 months duration to improve performance.
