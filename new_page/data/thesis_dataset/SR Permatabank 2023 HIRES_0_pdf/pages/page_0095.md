# 4. Women with Disabilities Enhancement Program

Program ini ditujukan kepada para perempuan penyandang disabilitas yang membutuhkan kelengkapan alat gerak atau alat bantu dengan untuk mempermudah mobilitas dan produktivitas mereka sehari-hari. Sasaran utama program ini adalah perempuan penyandang disabilitas yang memiliki peran sebagai tulang punggung keluarga. Pada tahun 2023, Program ini dilaksanakan di Jawa, Sumatera, Sulawesi, Bali dan Lombok dengan jumlah penerima manfaat sebanyak 50 orang.

# 4. Women with Disabilities Enhancement Program

This program is aimed at women who require mobility or hearing aids to help with daily activities and increase productivity, particularly those who serve as breadwinners in the family. In 2023, this was implemented in Java, Sumatra, Sulawesi, Bali, and Lombok, benefiting a total of 50 individuals.
