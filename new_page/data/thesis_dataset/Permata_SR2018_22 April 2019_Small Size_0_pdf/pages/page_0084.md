Akerat PermataBank

Di masa depan, kami mengharapkan untuk memiliki lebih banyak penyandang disabilitas yang berkarier di PermataBank. Untuk itu, PermataBank aktif bekerja sama dengan komunitas dan lembaga pemberdayaan untuk mencari dan membina kandidat penyandang disabilitas. Upaya ini telah dilaksanakan melalui program PermataHati BRAVE: Because eveRyone is Able &amp; CreatiVE sejak tahun 2017, yang dapat anda baca di halaman 51. [GRI 103-3]

In the future, we hope more people with disabilities can join PermataBank. To that end, PermataBank now actively cooperates with communities and empowerment institutions to find and foster candidates with disabilities. This effort has been carried out through the program PermataHati BRAVE: Because eveRyone is Able &amp; CreatiVE since 2017, which you can read about on page 51. [GRI 103-3]
