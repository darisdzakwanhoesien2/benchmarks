# Machining Development Program (MDP) – Keterampilan Teknis untuk Komunitas Lokal

Machining Development Program (MDP) – Technical Skills for Local Communities

![img-86.jpeg](img-86.jpeg)

SSB melanjutkan Machining Development Program (MDP) pada tahun 2025 sebagai bagian dari komitmennya untuk membangun kapasitas teknis di Kalimantan. Program ini melatih 16 peserta dalam keterampilan pemesinan, tiga di antaranya kemudian dipekerjakan sebagai karyawan SSB. MDP mendukung pengembangan tenaga kerja lokal, meningkatkan kemampuan kerja, dan berkontribusi untuk meningkatkan mata pencaharian di masyarakat sekitar.

SSB continued its Machining Development Program (MDP) in 2025 as part of its commitment to building technical capacity in Kalimantan. The program trained 16 participants in machining skills, three of whom were subsequently hired as SSB employees. MDP supports local workforce development, enhances employability, and contributes to improving livelihoods in surrounding communities.
