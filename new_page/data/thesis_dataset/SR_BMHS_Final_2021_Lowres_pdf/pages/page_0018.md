Nilai Budaya Keberlanjutan
Sustainability Cultural Values

11 Budaya Baik BMHS meliputi Adab, Ilmu, dan Mahir.
11 Culture of Goodness of BMHS include Courtesy, Knowledge, and Proficiency.

|  Adab/Courtesy  |   |
| --- | --- |
|  Jujur | Dapat dipercaya dalam menjalankan pekerjaan dan perintah dari pimpinan  |
|  Honest | Trustworthy in carrying out work and orders from the leaders  |
|  Sopan | Bertindak sesuai dengan norma dan berakhlak serta beretika  |
|  Polite | Acting in accordance with norms and possessing good character/ethics  |
|  Disiplin | Senantiasa mematuhi tata tertib dan aturan perusahaan dalam wujud perbuatan dan tindakan yang dilakukan  |
|  Dicipline | Always complying with company rules and regulations shown in behaviors and actions  |
|  Setia | Berdedikasi dan mengutamakan kepentingan Bangsa dan Negara  |
|  Loyal | Dedicated and prioritizing the best interests of the Nation and the State  |
|  Semangat Kerja | Keinginan diri untuk bekerja dengan sungguh-sungguh untuk mencapai hasil yang di-harapkan  |
|  Good Work Ethic | Self desire to work intently to achieve the expected results  |
|  Bertanggung Jawab | Berani dan siap melakukan serta menanggung segala sesuatu hal yang muncul akibat perbuatan yang dilakukan  |
|  Responsible | Be brave and ready to execute and carry everything that arises as the result of the actions taken  |
|  Bekerja Sama | Mampu menciptakan hubungan kerja yang baik dengan rekan sekerja, atasan dan lingkungan sekitar  |
|  Cooperative | Able to create good working relationships with co-workers, superiors, and the surrounding environment  |
|  Ilmu/Knowledge  |   |
|  Menguasai Pekerjaan | Memiliki pengetahuan yang baik secara teori dan teknis terkait pekerjaan yang menjadi tugas pokok dan tanggung jawab  |
|  Masterful | Possessing adequate theoretical and technical knowledge related to work that is the main task and responsibility  |
|  Mahir/Proficiency  |   |
|  Produktif | Mampu memberikan hasil  |
|  Productive | Able to deliver results  |
|  Berani Bergagas dan Berkeputusan | Berani menyampaikan pendapat dan ide positif yang membangun  |
|  Dare-to Think and Decide | Dare to express constructive opinions and positive ideas  |
|  Berjiwa Pemimpin | Senantiasa tampil dan bersikap memimpin secara adil dan bijaksana, lugas, dan menjadi panutan bagi rekan kerja  |
|  Leader Spirited | Always showing up and leading fairly, wisely, and in a straightforward manner, as well as being a role model for colleagues  |
