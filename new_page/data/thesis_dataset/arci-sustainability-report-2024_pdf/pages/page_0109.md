Cetatan / Note:
FR dan SR dihitung berdasarkan 1.000.000 jam kerja.
FR: jumlah korban kecelakaan x 1.000.000/jumlah jam kerja kumulatif.
SR: jumlah hari kerja hilang x 1.000.000/jumlah jam kerja kumulatif.
FR and SR are calculated based on 1,000,000 working hours.
FR: number of accident victims x 1,000,000/total cumulative working hours.
SR: number of lost workdays x 1,000,000/total cumulative working hours.
