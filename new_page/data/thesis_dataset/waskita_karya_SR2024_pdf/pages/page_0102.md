## 2023: Elevate

Peningkatan kapabilitas dan kompetensi talent pada setiap bidang spesialisasi Waskita menjadi target utama pada tahun 2023. Selain itu, penerapan program budaya yang berlandaskan dan core values yakni 'AKHLAK' untuk menciptakan nilai tambah bagi Perusahaan.
