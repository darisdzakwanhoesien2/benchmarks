BTN Mobile

In 2023, the company launched BTN Mobile super app. This SuperApp is an improvement on the previous mobile banking service. BTN Mobile is present as an integrated app that offers various service features in one app. BTN Mobile is connected to the BTN Bank ecosystem so users can access various other digital solutions such as BTN Properti, virtual branches, e-mitra and inexpensive homes.

By simply using one device, customers can easily carry out various banking services directly, anytime, anywhere.

Features available in BTN Mobile include:

- QRIS BTN Mobile;
- Cardless account;
- Auto Debit System;
- Auto Transfer;
- Opening Account; and
- BTN KITA (appropriate digital credit).
