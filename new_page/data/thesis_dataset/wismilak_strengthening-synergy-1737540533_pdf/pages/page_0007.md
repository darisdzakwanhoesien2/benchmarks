# Pesan Direktur Utama
Message from the
President Director 1102-14

Ronald Walla
Direktur Utama
President Director

![img-27.jpeg](img-27.jpeg)

"Kami memahami pentingnya menciptakan nilai bagi kelompok pemangku kepentingan, termasuk karyawan, pelanggan, pemasok, dan masyarakat. Untuk itu, Wismilak berupaya mengelola risiko dan peluang aspek lingkungan, sosial, tata kelola (LST), serta menciptakan nilai untuk jangka panjang. Guna mewujudkan hal ini maka kami perlu memperkuat sinergi dengan seluruh pemangku kepentingan."

"We understand the importance of creating value for stakeholder groups, including employees, consumers, suppliers, and communities. Therefore, Wismilak strives to manage risks and opportunities in the environmental, social, and governance (ESG) aspects as well as create long term value. To make this a reality, we need to strengthen synergy with all stakeholders."
