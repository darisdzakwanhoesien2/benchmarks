# INDEKS KEPUASAN PENERIMA MANFAAT

Program PermataHati CSR yang telah dijalankan PermataBank diharapkan mampu memberikan manfaat dan dampak luas kepada masyarakat sekitar. Dalam upaya mengetahui sejauh mana efektivitas pelaksanaan program-program tersebut, PermataBank selalu mengumpulkan data umpan balik dari para penerima manfaat CSR di setiap akhir program yang dijalankan. Data ini digunakan oleh tim PermataHati sebagai bahan evaluasi untuk perbaikan pelaksanaan program di waktu yang akan datang.
