## Program Pengembangan Kompetensi SDM [404-2]

Program Pengembangan Kompetensi SDM dilakukan dengan menyelaraskan kebutuhan dan rencana pengembangan SDM sesuai arah pengembangan perusahaan ke depan. Beberapa program pelatihan dan pengembangan yang dilakukan secara rutin antara lain:

1. Leadership Development Program for Director &amp; Commissioner;
2. Leadership Development Program for General Manager;
3. Leadership Development Program for Middle Manager;
4. Leadership Development Program for Project Manager and Superintendent;
5. Leadership Development Program for Junior Manager;
6. Leadership Development Program for Legal.
