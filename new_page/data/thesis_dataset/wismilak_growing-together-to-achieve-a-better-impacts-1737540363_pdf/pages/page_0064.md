# Waktu Kegiatan: Activity Time:

## Oktober | October 2023

### Nama Kegiatan: Event:

Festival Karapan Sapi Piala Presiden Madura 2023 Madura President Cup Bull Race Festival 2023

### Uraian Kegiatan: Activity Description:

Setiap tahun Wismilak menggelar Festival Karapan Sapi Madura Piala Presiden sebagai program tahunan yang dalam upaya menjaga dan melestarikan budaya Indonesia.

Every year, Wismilak holds the Madura Bull Race Festival President's Cup as an annual program to maintain and preserve Indonesian culture.

# Waktu Kegiatan: Activity Time:

## November 2023

### Nama Kegiatan: Event:

Program Aksiliterasi Wismilak Wismilak ActionLiteracy Program

### Uraian Kegiatan: Activity Description:

Program Aksiliterasi Wismilak bekerja sama dengan Gabungan Organisasi Wanita Surabaya. Sebagai program komplimentari, Wismilak juga memberikan paket belajar Koding dan Robotika kepada sekolah terpilih, berkolaborasi dengan Koding Akademi yang merupakan alumni program kewirausahaan Wismilak, Diplomat Success Challenge.

The Wismilak Aksiliterasi Program collaborates with the Surabaya Women's Organization. As a complementary program, Wismilak also provides Coding and Robotics learning packages to selected schools in collaboration with Koding Akademi, an alumni of the Wismilak Diplomat Success Challenge entrepreneurship program.
