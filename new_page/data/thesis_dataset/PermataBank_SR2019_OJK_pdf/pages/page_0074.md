PermataBank telah memiliki framework untuk learning &amp; development yang digunakan sebagai landasan pengembangan talenta karyawan. Kerangka kerja tersebut terbagi menjadi empat pilar seperti tergambar di bawah ini:

PermataBank has established a framework for learning &amp; development that is used as a foundation for employee talent development. The framework is divided into four pillars as illustrated below:

![img-68.jpeg](img-68.jpeg)

# 1. Leadership Development Program

Program pengembangan kepemimpinan didesain sesuai dengan tingkat jabatan untuk meningkatkan efektivitas pembelajaran.

Leadership development program that is designed according to the level of position to improve learning effectiveness.

# 2. Functional Development Program

Program pengembangan technical skill yang mencakup semua tingkatan kecakapan.

Program for developing technical skills that covers all levels of proficiency.

# 3. Character Building

Merupakan pengembangan area softskill dan VMV Internalization.

Which is the development of the soft skill area and VMV Internalization.

# 4. Acceleration Program

Program yang didesain untuk para talenta.

Program designed for talents.
