# RENCANA MASA DEPAN

Sebagai langkah proaktif menghadapi tantangan bisnis dan memanfaatkan teknologi secara optimal, Operations akan terus meninjau dan menyempurnakan system, mengembangkan inisiatif otomasi, serta memperkuat proses melalui kolaborasi dengan direktorat terkait. Di sisi pengembangan SDM, Operations akan melaksanakan kerangka pembelajaran yang dirancang khusus untuk tim operasional, sekaligus menegakkan budaya pengendalian risiko yang kokoh guna mendukung keberlangsungan operasional.

Berikut inisiatif yang termasuk dalam perencanaan tahun 2026, yaitu:

1. Pengembangan sistem berbasis Fuzzy Logic untuk mendukung transaksi penerimaan dan melalui SKN, RTGS, dan Remittance.
2. Pengembangan lanjutan applikasi kustodian bank yang difokuskan pada peningkatan akurasi identifikasi produk, otomasi proses perhitungan pajak, serta pengembangan fungsi tambahan untuk transaksi saham maupun obligasi.
3. Penguatan fungsi core banking pada proses kredit modal kerja, dengan penambahan fitur monitoring otorisasi transaksi yang lebih baik.

4. Pengembangan sistem registrasi dan monitoring terintegrasi untuk dokumen pendukung transaksi valuta asing (foreign exchange) dan instrumen derivative.
5. Melanjutkan pengembangan sistem manajemen User ID terintegrasi untuk meningkatkan kontrol dan mempercepat pengelolaan User ID serta proses pendaftaran atau perubahan parameter internal.
6. Melanjutkan pengembangan pada proses pelaporan ke Regulator yang meliputi Pelaporan Antasena dan Pelaporan SLIK, serta melakukan penyesuaian sesuai dengan ketentuan yang berlaku.
7. Mengadakan program pelatihan dan mentoring untuk meningkatkan kompetensi karyawan, termasuk keterampilan interpersonal seperti kepemimpinan dan orientasi layanan.
8. Beradaptasi dan berusaha mengoptimalkan penggunaan AI dalam kegiatan operasional (untuk fungsi kontrol, monitoring, proses, dan lain-lain) dengan menggunakan aplikasi 'Copilot'.
9. Implementasi pergantian sistem Treasury baru untuk mengoptimalkan input transaksi, penyelesaian, dan pelaporan untuk mengurangi manual input, meminimalisir human error, dan meningkatkan SLA (Service Level Agreement).
