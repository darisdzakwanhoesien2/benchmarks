|  Mekanisme pengambilan keputusan Rapat Mechanism of Meeting Decision-Making | Semua keputusan diambil dengan cara musyawarah untuk mufakat. If consensus cannot be reached, a vote is taken by counting the number of shares that vote agree, abstain or disagree.  |   |   |
