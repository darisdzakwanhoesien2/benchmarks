# Akses Informasi Atas Laporan Keberlanjutan

Laporan ini ditujukan kepada seluruh Pemangku Kepentingan sebagai salah satu landasan melakukan penilaian atas kinerja Perseroan. Dengan demikian, para Pemangku Kepentingan dapat melakukan evaluasi mengenai sejauh mana Perseroan berperan serta dalam menjalankan kewajibannya bagi keberlanjutan di bidang lingkungan, ekonomi dan sosial terkait praktik bisnisnya. Untuk itu, kami mempersilakan para pengguna laporan ini untuk menyampaikan saran dan umpan balik dari para pembaca untuk perbaikan Laporan Berkelanjutan periode mendatang.
