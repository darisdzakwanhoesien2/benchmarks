# CSR DI BIDANG PENGEMBANGAN SOSIAL DAN KEMASYARAKATAN [GRI 203-2]

Kegiatan pengembangan sosial dan kemasyarakatan Grup BNBR terangkum dalam Bakrie Untuk Negeri yang terdiri dari 4 program utama, yakni Cerdas Untuk Negeri, Sehat Untuk Negeri, Peduli Untuk Negeri, dan Kemitraan Untuk Negeri. Grup BNBR berkomitmen untuk meningkatkan taraf hidup masyarakat dari aspek kesehatan, pendidikan, serta ekonomi melalui 4 program tersebut.

# PEMBERDAYAAN MASYARAKAT SEKITAR PERUSAHAAN [SEOJK F.25]

BNBR dan anak-anak usahanya sangat menaruh perhatian terhadap pembangunan manusia serta peningkatan kualitas hidup masyarakat Indonesia. [SEOJK F.23] [GRI 413-1]

# PROGRAM KEMITRAAN UNTUK NEGERI

Program Kemitraan untuk Negeri menawarkan kesempatan bagi pengusaha lokal di sekitar wilayah operasional untuk mengembangkan potensi kemitraan dengan perusahaan dalam bentuk kesempatan bekerja maupun kerjasama bisnis. Kegiatannya mencakupi kemitraan antara perusahaan dengan warga sekitar dalam pengelolaan kebersihan lingkungan, membangun dan menyediakan fasilitas olahraga di dalam pabrik dan membukanya secara umum dan gratis agar dapat dipakai masyarakat setempat, dan penyediaan dana modal usaha untuk pengembangan produk potensi daerah.

Pada tahun 2023, telah terlaksana beberapa kegiatan Program Kemitraan untuk Negeri, di antaranya:

- Bantuan alat kantor di Kantor Desa Sumuranja dan di Polda Airud Banten oleh PT Bakrie Construction (BCons).
- Mendukung UMKM warga sekitar (Bubur Kacang Hijau) di sekitar wilayah PT Braja Mukti Cakra (BMC).
